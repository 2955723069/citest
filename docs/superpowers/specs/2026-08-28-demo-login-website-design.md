# 演示登录网站设计

## 目标

创建一个无需后端和构建工具的响应式演示网站。用户在登录页填写任意非空账号和密码后进入欢迎页，并可从欢迎页访问百度、必应或 GitHub。

## 技术方案

网站使用原生 HTML、CSS 和 JavaScript，包含两个独立页面：

- `index.html`：登录页。
- `welcome.html`：登录后的欢迎页及外部链接入口。
- `styles.css`：两页共用的视觉样式与响应式规则。
- `login.js`：登录表单校验、登录状态保存和页面跳转。
- `welcome.js`：访问控制、用户名展示和退出登录。

此方案不依赖 Node.js 或第三方库，可以通过静态服务器运行。

## 页面与交互

### 登录页

登录页采用浅灰白背景、白色登录面板和蓝色重点色。页面包含网站标识、账号输入框、密码输入框、显示或隐藏密码按钮、登录按钮和表单错误提示。

账号和密码均为必填项。提交有效表单后，将用户名写入 `sessionStorage`，然后跳转到 `welcome.html`。表单无效时留在当前页面，在对应控件附近显示可访问的错误信息，并将焦点移至第一个无效输入框。

### 欢迎页

欢迎页显示当前用户名和三个外部链接入口：百度、必应和 GitHub。外部链接在新标签页打开，并使用安全的 `rel` 属性。页面还提供退出按钮；退出会清除本次会话的登录状态并返回登录页。

如果用户未登录便直接访问 `welcome.html`，脚本会将其重定向到 `index.html`。

## 状态与数据流

登录状态仅保存在浏览器的 `sessionStorage` 中，键名固定且只存储演示用户名。关闭标签页或浏览器会话后状态自然失效，不会持久保存密码。

数据流为：填写表单 -> 前端校验 -> 保存用户名 -> 打开欢迎页 -> 读取并展示用户名。退出时执行相反流程：清除用户名 -> 返回登录页。

## 视觉与响应式设计

整体使用现代简洁风格，颜色以中性灰白为主，蓝色用于主要操作，另使用少量绿色表示已登录状态。卡片圆角不超过 8px，控件提供清晰的悬停、聚焦和禁用状态。

桌面端登录面板保持紧凑居中；移动端缩小外边距并让主要控件占满可用宽度。页面使用稳定的尺寸约束，避免交互状态导致布局跳动。所有功能支持键盘操作，并遵循用户的减少动画偏好。

## 错误处理与安全边界

本网站只演示登录流程，不执行真实身份验证，也不应存放敏感信息。密码不会写入任何存储。JavaScript 不可用时，页面仍能展示内容，但登录流程需要 JavaScript 才能完成。

## 验证

验证范围包括：

- 账号或密码为空时不能提交，并显示正确错误提示。
- 任意非空账号和密码可以登录。
- 登录后欢迎页显示正确用户名。
- 未登录直接访问欢迎页会返回登录页。
- 外部链接地址、打开方式和安全属性正确。
- 退出后无法继续直接访问欢迎页。
- 桌面和移动尺寸下无文字溢出、控件重叠或横向滚动。
- 键盘焦点、显示密码按钮和减少动画设置正常工作。
